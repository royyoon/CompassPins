# CompassPins

CompassPins helps parents and children track their progress through the Adventure Guides Compass Journey program. Stay organized and motivated as your explorer earns pins across all four journey directions.

## Features

- **Track Progress**: See your child's pin achievements across all four journeys - North (Family), East (Nature), South (Community), and West (Fun)
- **Visual Journey Compass**: Beautiful interface showing progress in each direction with earned pins, rockers, and medallions
- **Pin Details**: View detailed requirements, examples, and visual guides for each pin activity
- **Submit for Approval**: Submit completed pins directly to your Circle's Pin Wizard for review
- **Multiple Children**: Support for families with multiple explorers
- **Offline Support**: View cached progress even without internet connection

## Requirements

- iOS device (iPhone or iPad)
- Google account registered with your Adventure Guides Circle
- Active participation in an Adventure Guides program
- Access provided by your Circle's Pin Wizard
